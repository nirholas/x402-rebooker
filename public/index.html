Paying for a call

An unpaid request answers 402 with a dual-rail challenge — USDC on Base and USDC on Solana. Each accepts entry carries an outputSchema describing exactly how to build the request and what the 200 body will contain, so an agent can call the route correctly on its first paid attempt.

import { wrapFetchWithPayment } from "x402-fetch";

const pay = wrapFetchWithPayment(fetch, wallet);
const res = await pay("http://localhost:4043/scan");
const data = await res.json();
